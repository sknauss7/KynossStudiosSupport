# KynossStudiosSupport
## Who edits what

- **The /systems/ page belongs to the Systems workspace** (`~/Systems`, Callia session `systems`). Its files are `_build/systems.json` (all the words), `_build/templates/systems.html` (layout), `assets/systems.css` (styles), plus the build outputs `systems/index.html` and `assets/og/systems.png`. Other sessions leave those files alone; a normal build still regenerates the outputs.
- **Everything else belongs to AgentWorkshop**, including the shared chrome (nav, footer, `base.html`, `site.css`). `/hoa/` is only a redirect to `/systems/` now (the HOA concept page was folded in on 2026-10-08).
